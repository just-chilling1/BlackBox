# Voice Reference Set (canonical taste anchors)

Owner-approved scripts bundled so the skill works standalone — no external
repo or output folder needed. Match the **register** of these files, never
their branding: product names, feature names, prices, and URLs inside them
belong to past products and must NOT leak into a new software's scripts.

| File | What it anchors |
|---|---|
| `dashboard-01-buyers-remorse.md` | Track A persuasion register — videos 1 & 2 (hand-cleaned) |
| `dashboard-03-quick-overview.md` | The quick-tour register — shallow map, not in-depth |
| `academy-first-core-tool.md` | First academy video — core tool, "first video of your in-depth training" opener |
| `academy-premium-with-ad.md` | Mid-series premium feature WITH a generation wait → contains the one woven free-training ad block |
| `academy-final-no-ad.md` | Final academy video — final opener, "I'll see you inside" sign-off, security/static page → ZERO ad mentions |

The academy files are the owner's hand-edited voice (merged flowing paragraphs,
".." breath pauses, casual grammar with clean spelling, personality beats).
`ACADEMY-SERIES-STYLE.md` codifies the rules extracted from them; when a rule
feels ambiguous, these files win.
